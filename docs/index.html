WinGetty is a private winget repository for managed and air-gapped environments. Download installers once on a connected machine, import them automatically, and let users browse a catalog and install with the winget they already know.

How it works

Three moving parts, no cloud dependency. Everything runs on your network.

  1. Download once, connected

    On a machine with internet access, winget download pulls the installer plus a YAML manifest describing it. Drop the folders into your artifact store or a shared folder.

  2. Import automatically

    The importer reads every manifest, verifies each installer’s SHA256, and registers packages in WinGetty - scheduled, repeatable, and with a report of what was added or skipped.

  3. Users install from the catalog

    End users open the catalog, click Install (a safe wingetty:// handler runs winget with fixed arguments) or copy the standard winget install command.
